# Проект course_work_2
## Описание:
Проект courswork_2 - это проект, который получает информацию 
о вакансиях с платформы hh.ru в России.

## Функции:
Используемые функции: 
 - filter_vacancies - фильтрация по ключевым словам 
 - get_by_salary - фильтрация по зарплате 
 - sort_vacancies - сортировка по убыванию зарплаты 
 - get_top - Топ N print_vacancies - Читаемый вывод

Запуск программы
Убедитесь, что установлен Python 3.7+
Установите зависимости: poetry add requests
Запустите: main.py`
Следуйте инструкциям в консоли:
Введите поисковый запрос (например: "менеджер") - дождитесь ответа на запрос.
Укажите количество вакансий для вывода (топ N)
При необходимости введите ключевые слова для фильтрации
При необходимости укажите диапазон зарплат (формат: min-max)
Программа сохраняет вакансии в файл data/vacancies.json
